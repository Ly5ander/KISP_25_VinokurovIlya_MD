## Лекционное задание № 2. Знакомство с JavaScript

### 1. Введение в JavaScript
* **Назначение:** JavaScript изначально создавался для того, чтобы сделать веб-страницы «живыми». Программы на этом языке называются **скриптами**. Они встраиваются прямо в HTML и выполняются автоматически при загрузке страницы.
* **Где выполняется:** в браузере, на сервере (**Node.js**) или на любом устройстве, где есть **движок JavaScript** (V8 в Chrome/Edge/Node.js, SpiderMonkey в Firefox, JavaScriptCore в Safari).
* **Как работает движок:**
  1. Читает (парсит) текст скрипта.
  2. Компилирует скрипт в машинный код (JIT-компиляция).
  3. Выполняет машинный код на высокой скорости.
* **Что умеет JS в браузере:** добавлять новый HTML на страницу, изменять содержимое и стили, реагировать на действия пользователя (клики, движение мыши, нажатия клавиш), отправлять сетевые запросы (AJAX, `fetch`), работать с `cookies` и `localStorage`.
* **Чего НЕ умеет JS в браузере (ради безопасности):** читать/записывать произвольные файлы на жёстком диске без участия пользователя, обращаться к данным других вкладок/доменов (правило одного источника — Same Origin Policy).

### 2. Справочники и спецификации
* **Спецификация ECMA-262:** официальный стандарт языка ECMAScript. Обновляется ежегодно.
* **MDN (Mozilla Developer Network):** лучший справочник с описанием синтаксиса, параметров и примеров (`developer.mozilla.org`).
* **Can I Use (`caniuse.com`):** таблицы совместимости технологий с конкретными версиями браузеров.
* **Kangax (`compat-table.github.io`):** таблица поддержки новейших возможностей стандарта ES.

### 3. Редакторы кода
* **IDE (Integrated Development Environment):** среда разработки для работы с целыми проектами (автодополнение, отладчик, интеграция с Git): **Visual Studio Code**, **WebStorm**.
* **Облегчённые редакторы:** подходят для быстрого редактирования отдельных файлов: **Sublime Text**, **Notepad++**, **Vim**.

### 4. Консоль разработчика
Открывается в браузере клавишами **`F12`**, **`Ctrl + Shift + I`** (Windows/Linux) или **`Cmd + Option + I`** (Mac).
* Позволяет просматривать ошибки выполнения (подсвечиваются красным) и запускать команды вручную (для переноса строки в консоли используется `Shift + Enter`).
* Основные команды объекта `console`:

    console.log('Текст сообщения', 123);       // Вывод информации
    console.info('Информационное сообщение');  // Инфо
    console.warn('Предупреждение');            // Жёлтое предупреждение
    console.error('Ошибка!');                  // Красная ошибка
    console.table([{ name: 'Анна', age: 20 }, { name: 'Иван', age: 22 }]); // Таблица
    console.clear();                           // Очистить консоль

### 5. Основы JavaScript: «Привет, мир!»
* **Тег `<script>`:** вставляется в HTML-документ.

    <!DOCTYPE HTML>
    <html>
    <body>
      <script>
        alert('Привет, мир!');
      </script>
    </body>
    </html>

* **Подключение внешнего скрипта:** используется атрибут `src` (если указан `src`, содержимое внутри тега `<script>...</script>` игнорируется):

    <script src="/js/script1.js"></script>
    <script src="https://cloudflare.com"></script>

### 6. Структура кода
* **Инструкции:** команды языка (`alert('Привет');`). Разделяются точкой с запятой `;`. Перенос строки часто работает как автоматическая вставка `;`, но бывают исключения (например, перед квадратными скобками `[...]`), поэтому рекомендуется всегда ставить `;`.
* **Комментарии:** удаляются движком при выполнении.

    // Однострочный комментарий

    /*
      Многострочный
      комментарий
    */

### 7. Строгий режим — `"use strict"`
* Введён в стандарте ES5 для устранения устаревшего поведения и скрытых ошибок (например, запрещает присваивание в необъявленную переменную).
* Ставится первой строкой скрипта или в начале функции:

    "use strict";

    x = 5; // ReferenceError: x is not defined

* В современных `class` и ES-модулях (`import`/`export`) строгий режим включён автоматически.

### 8. Переменные
Переменная — именованное хранилище для данных.
* **`let`** — современная переменная, значение можно менять:

    let message = 'Hello';
    message = 'World';

* **`const`** — константа, значение нельзя перезаписать:

    const myBirthday = '18.04.1982';
    const COLOR_ORANGE = '#FF7F00'; // Заглавные буквы для заранее известных жёстких констант

* **`var`** — устаревшее объявление (игнорирует блоки `if`/`for`, всплывает вверх функции).
* **Правила именования:** имя может содержать буквы, цифры, символы `$` и `_`, но не должно начинаться с цифры. Используется стиль `camelCase` (`userName`, `shoppingCart`). Регистр имеет значение (`apple` и `APPLE` — разные переменные).

### 9. Типы данных
JavaScript — динамически типизированный язык (переменная может менять тип). Всего **8 типов данных**:
1. **`number`** — целые и дробные числа (`10`, `3.14`), а также специальные числовые значения: `Infinity`, `-Infinity`, `NaN` (вычислительная ошибка, например `'текст' / 2`).
2. **`bigint`** — целые числа произвольной длины (добавляется `n` в конце): `const bigInt = 1234567890123456789012345678901234567890n;`.
3. **`string`** — строка. Три вида кавычек:
   * Двойные `"Привет"` и одинарные `'Привет'` — равнозначны.
   * Обратные — позволяют встраивать переменные и выражения через `${...}` и делать многострочный текст.
4. **`boolean`** — логический тип: `true` (истина) или `false` (ложь).
5. **`null`** — специальное значение, обозначающее «ничего», «пусто» или «значение неизвестно».
6. **`undefined`** — означает, что «значение не было присвоено» (переменная объявлена, но не заполнена).
7. **`symbol`** — используется для создания уникальных идентификаторов в объектах (`Symbol('id')`).
8. **`object`** — не примитивный тип; используется для хранения коллекций данных и сложных структур (объекты `{}`, массивы `[]`, функции).

* **Оператор `typeof`:** возвращает строку с именем типа:

    typeof undefined; // "undefined"
    typeof 0;         // "number"
    typeof 10n;       // "bigint"
    typeof true;      // "boolean"
    typeof "foo";     // "string"
    typeof Symbol();  // "symbol"
    typeof Math;      // "object"
    typeof null;      // "object" (известная историческая ошибка языка)
    typeof alert;     // "function" (функции относятся к объектам, но typeof выделяет их)

### 10. Взаимодействие: `alert`, `prompt`, `confirm`
Все три функции являются **модальными** — они приостанавливают выполнение скрипта, пока пользователь не закроет окно.

    // 1. alert — простое уведомление
    alert('Добро пожаловать!');

    // 2. prompt — запрос текста от пользователя
    // title — текст вопроса, default — необязательное значение по умолчанию
    let age = prompt('Сколько тебе лет?', 18); // вернёт строку или null (если нажата Отмена/Esc)

    // 3. confirm — вопрос с выбором Да / Нет
    let isReady = confirm('Вы готовы начать?'); // вернёт true (ОК) или false (Отмена)

## Лекционное задание № 3. Основы JavaScript

### 1. Преобразование типов
* **Строковое преобразование — `String(value)`:**

    String(true);      // "true"
    String(null);      // "null"
    String(undefined); // "undefined"
    String(123);       // "123"

* **Численное преобразование — `Number(value)`:** происходит автоматически при математических операциях (`/`, `*`, `-`, `%`).

  | Исходное значение | Результат `Number(...)` |
  | :--- | :--- |
  | `undefined` | `NaN` |
  | `null` | `0` |
  | `true` / `false` | `1` / `0` |
  | `""` (пустая или пробельная строка) | `0` |
  | `"  123  "` (строка с числом) | `123` (пробелы по краям обрезаются) |
  | `"123abc"` (строка с буквами) | `NaN` |

* **Логическое преобразование — `Boolean(value)`:**
  * Значения, которые становятся **`false`** (falsy-значения): `0`, `""` (пустая строка), `null`, `undefined`, `NaN`.
  * Все остальные значения становятся **`true`** (включая строку `"0"` и строку с пробелом `" "`).

### 2. Базовые операторы, математика
* **Термины:** *операнд* — то, к чему применяется оператор; *унарный* оператор работает с одним операндом (`-x`), *бинарный* — с двумя (`x + y`).
* **Арифметика:**

    5 + 2;  // 7 (сложение)
    5 - 2;  // 3 (вычитание)
    5 * 2;  // 10 (умножение)
    5 / 2;  // 2.5 (деление)
    5 % 2;  // 1 (остаток от деления)
    2 ** 3; // 8 (возведение в степень: 2 в степени 3)
    4 ** (1/2); // 2 (квадратный корень)

* **Сложение строк бинарным `+`:** если хотя бы один операнд — строка, второй приводится к строке:

    '1' + 2;     // "12"
    2 + 2 + '1'; // "41" (сначала 2 + 2 = 4, затем 4 + '1' = "41")
    '1' + 2 + 2; // "122"

* **Унарный плюс `+`:** работает как `Number(...)`, переводя нечисла в числа:

    let apples = "2";
    let oranges = "3";
    alert(+apples + +oranges); // 5

* **Приоритет операторов (от высшего к низшему):** унарный плюс/минус (`+`, `-`) -> возведение в степень (`**`) -> умножение/деление (`*`, `/`, `%`) -> сложение/вычитание (`+`, `-`) -> присваивание (`=`).
* **Сокращённая арифметика и инкремент/декремент:**

    let n = 2;
    n += 5; // 7 (то же, что n = n + 5)
    n *= 2; // 14

    let a = 1;
    let b = ++a; // префиксная форма: a = 2, b = 2 (возвращает новое значение)
    let c = a++; // постфиксная форма: c = 2, a = 3 (возвращает старое значение)

* **Побитовые операторы:** `&` (И), `|` (ИЛИ), `^` (ИСКЛЮЧАЮЩЕЕ ИЛИ), `~` (НЕ), `<<` (сдвиг влево), `>>` (сдвиг вправо), `>>>` (беззнаковый сдвиг вправо).
* **Оператор запятая `,`:** вычисляет несколько выражений, но возвращает результат только последнего: `let x = (1 + 2, 3 + 4); // 7`.

### 3. Операторы сравнения
* **Базовые операторы:** `>`, `<`, `>=`, `<=`, `==`, `!=`, `===`, `!==`. Всегда возвращают `boolean`.
* **Сравнение строк:** сравниваются посимвольно в лексикографическом порядке (по кодам символов Unicode: `'а' > 'Я'`, `'Кот' > 'Код'`).
* **Сравнение разных типов:** значения приводятся к числам (`'2' > 1` -> `true`, `true == 1` -> `true`, `false == 0` -> `true`).
* **Строгое равенство `===` и неравенство `!==`:** проверяет равенство **без приведения типов**:

    0 == false;  // true
    0 === false; // false (разные типы: number и boolean)

* **Особенности `null` и `undefined`:**

    null === undefined; // false
    null == undefined;  // true (специальное правило языка: равны друг другу и больше ничему)
    null > 0;           // false (при > null преобразуется в 0: 0 > 0 -> false)
    null == 0;          // false (при == null не преобразуется в число)
    null >= 0;          // true (0 >= 0 -> true)

### 4. Условное ветвление: `if`, `'?'`
* **Блок `if / else if / else`:**

    let score = 85;

    if (score >= 90) {
      console.log('Отлично');
    } else if (score >= 75) {
      console.log('Хорошо');
    } else {
      console.log('Нужно подтянуть');
    }

* **Условный (тернарный) оператор `?`:** единственный оператор в JS с тремя операндами:

    // Синтаксис: let result = условие ? значение1 : значение2;
    let age = 20;
    let access = (age >= 18) ? 'Доступ разрешён' : 'Доступ запрещён';

    // Несколько условий:
    let greeting = (age < 3) ? 'Здравствуй, малыш!' :
      (age < 18) ? 'Привет!' :
      (age < 100) ? 'Здравствуйте!' : 'Какой необычный возраст!';

### 5. Логические операторы
* **`||` (Логическое ИЛИ):**
  1. Вычисляет операнды слева направо.
  2. Каждый операнд конвертирует в логический тип.
  3. Останавливается на первом истинном значении и возвращает его **исходное значение** (не преобразованное в `boolean`).
  4. Если все ложны — возвращает последний операнд.

    alert(null || 0 || 'Первый истинный' || 1); // 'Первый истинный'

* **`&&` (Логическое И):**
  1. Вычисляет слева направо.
  2. Останавливается на первом ложном значении и возвращает его исходное значение.
  3. Если все истинны — возвращает последний операнд.
  4. Приоритет `&&` выше, чем у `||`.

    alert(1 && 2 && null && 3); // null
    alert(1 && 2 && 3);         // 3

* **`!` (Логическое НЕ):** приводит к `boolean` и возвращает противоположное значение:

    !true;     // false
    !0;        // true
    !!"текст"; // true (двойное НЕ — аналог Boolean("текст"))

### 6. Операторы нулевого слияния и присваивания: `'??'`, `'??='`
* **Оператор нулевого слияния `??`:** возвращает первый аргумент, если он не `null` и не `undefined` (т.е. «определён»), иначе — второй.
  * Главное отличие от `||`: оператор `||` не различает `false`, `0`, `""` и `null`/`undefined`, а `??` реагирует **только** на `null` и `undefined`.
  * Запрещено смешивать `??` с `&&` и `||` без круглых скобок `(a || b) ?? c`.

    let count = 0;
    alert(count || 10); // 10 (ошибка логики, если 0 — валидное значение)
    alert(count ?? 10); // 0 (корректно!)

* **Оператор нулевого присваивания `??=`:** присваивает переменной значение справа только если переменная сейчас равна `null` или `undefined`:

    let userAge = null;
    userAge ??= 18; // userAge станет 18
    userAge ??= 25; // останется 18, так как уже определено

## Лекционное задание № 4. Основы JavaScript 2

### 1. Циклы `while` и `for`
* **Цикл `while` (с предусловием):**

    let i = 3;
    while (i > 0) {
      console.log(i);
      i--;
    }

* **Цикл `do...while` (с постусловием):** тело выполнится хотя бы 1 раз, даже если условие сразу ложно:

    let i = 0;
    do {
      console.log(i);
      i++;
    } while (i < 3);

* **Цикл `for`:**

    // for (начало; условие; шаг) { тело }
    for (let i = 0; i < 3; i++) {
      console.log(i); // 0, 1, 2
    }

  Любую часть `for` можно пропустить: `for (; i < 3; )` или бесконечный цикл `for (;;)`.
* **Директивы `break` и `continue`:**
  * `break` — немедленно прерывает весь цикл.
  * `continue` — прерывает только текущую итерацию и переходит к следующей.
* **Метки для `break` / `continue`:** позволяют выйти сразу из нескольких вложенных циклов:

    outer: for (let i = 0; i < 3; i++) {
      for (let j = 0; j < 3; j++) {
        if (i === 1 && j === 1) break outer; // выйдет из обоих циклов
        console.log(i, j);
      }
    }

### 2. Конструкция `"switch"`
Позволяет заменить длинную цепочку `if...else if`. Проверка на совпадение всегда выполняется на **строгое равенство (`===`)**.

    let browser = 'Chrome';

    switch (browser) {
      case 'Edge':
        alert('У вас Edge!');
        break;

      // Группировка нескольких case:
      case 'Chrome':
      case 'Firefox':
      case 'Safari':
        alert('Этот браузер поддерживается');
        break;

      default:
        alert('Неизвестный браузер');
    }

*Если забыть `break`, выполнение провалится в следующий `case` без проверки условия.*

### 3. Функции (Function Declaration)
* **Объявление и параметры:**

    function showMessage(from, text = 'текст не добавлен') { // параметр по умолчанию
      from = '*' + from + '*'; // изменение локальной копии параметра
      return from + ': ' + text; // возврат результата
    }

    let result = showMessage('Анна'); // "*Анна*: текст не добавлен"

* **Область видимости:**
  * Переменные, объявленные внутри функции (`let`/`const`), являются **локальными** и не видны снаружи.
  * Функция имеет полный доступ к **внешним (глобальным)** переменным и может их изменять.
* **Возврат значения (`return`):**
  * Функция без `return` или с пустым `return;` возвращает `undefined`.
  * Нельзя ставить перенос строки сразу после `return` — JS автоматически поставит `;` и вернёт `undefined`.
* **Именование функций:** функции — это действия, поэтому их имена обычно начинаются с глаголов: `get...` (вернуть значение), `calc...` (вычислить), `create...` (создать), `check...` (проверить).

### 4. Function Expression
* Создание функции как части выражения (присваивание в переменную):

    let sayHi = function() {
      alert('Привет!');
    };

    let func = sayHi; // копирование самой функции (без круглых скобок!)
    func();           // вызов скопированной функции

* **Функции-колбэки (callback):** функции, передаваемые в качестве аргументов в другие функции для последующего вызова:

    function ask(question, yes, no) {
      if (confirm(question)) yes();
      else no();
    }

    ask(
      'Вы согласны?',
      function() { alert('Вы согласились.'); },
      function() { alert('Вы отменили выполнение.'); }
    );

* **Главное отличие Function Declaration от Function Expression:**
  * *Function Declaration* создаётся движком до выполнения кода (Hoisting) — её можно вызывать **до** объявления в коде.
  * *Function Expression* создаётся только когда поток выполнения доходит до этой строки — вызвать раньше нельзя.

### 5. Стрелочные функции, основы
Более лаконичный синтаксис для создания функций:

    // 1. Несколько аргументов:
    let sum = (a, b) => a + b;

    // 2. Один аргумент (круглые скобки можно опустить):
    let double = n => n * 2;

    // 3. Без аргументов (пустые скобки обязательны):
    let sayHi = () => alert('Привет!');

    // 4. Многострочная стрелочная функция (нужны фигурные скобки и явный return):
    let calculate = (a, b) => {
      let result = a * b;
      return result + 10;
    };

### 6. Особенности JavaScript (итоговая сводка)
1. **Структура кода:** инструкции разделяются `;`. После `return` нельзя делать перенос строки перед возвращаемым выражением.
2. **Строгий режим:** `"use strict"` в начале файла включает современный стандарт языка.
3. **Переменные:** используются `let` и `const` (блочная область видимости `{ ... }`).
4. **Динамическая типизация и 8 типов данных:** `number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol`, `object`.
5. **Операторы:** строгое сравнение `===` не приводит типы; `??` отсеивает только `null` и `undefined`; `||` и `&&` возвращают исходные операнды.
6. **Циклы:** `while`, `do...while`, `for` с управлением через `break`, `continue` и метки.
7. **Функции:** являются объектами-значениями; существуют в трёх формах — *Function Declaration*, *Function Expression* и *стрелочные функции `=>`*.
