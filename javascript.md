## Лекционное задание № 2. Знакомство с JavaScript

### 1. Введение в JavaScript
**JavaScript** изначально создавался для того, чтобы сделать веб-страницы «живыми». Программы на этом языке называются **скриптами**. Они встраиваются прямо в HTML и выполняются автоматически при загрузке страницы.

Сегодня JavaScript работает не только в браузере, но и на сервере (с помощью платформы **Node.js**) или на любом устройстве, где установлен **движок JavaScript** (например, V8 в Chrome и Node.js или SpiderMonkey в Firefox). Движок читает текст скрипта, компилирует его в машинный код и быстро выполняет.

### 2. Справочники и спецификации
* **Спецификация ECMA-262** — официальный, самый глубокий и формальный документ, описывающий стандарт языка.
* **MDN (Mozilla Developer Network)** — главный практический справочник с описанием функций, методов и примерами ([developer.mozilla.org](https://mozilla.org)).
* **Can I Use** — сервис с таблицами поддержки конкретных возможностей языка в разных браузерах ([caniuse.com](https://caniuse.com)).

### 3. Редакторы кода
* **IDE (интегрированная среда разработки)** — мощный редактор для работы с большими проектами, включающий отладчик, автодополнение и работу с Git (**Visual Studio Code**, **WebStorm**).
* **Облегчённые редакторы** — быстрые программы для редактирования отдельных файлов (**Sublime Text**, **Notepad++**).

### 4. Консоль разработчика
Инструменты разработчика в браузере открываются клавишей **`F12`** (или **`Ctrl + Shift + I`**). Вкладка **Console** позволяет видеть ошибки в коде (они подсвечиваются красным) и выполнять команды JavaScript прямо на открытой странице.

Для вывода разных типов сообщений в консоль используется встроенный объект `console` и его методы:

```javascript
console.log('Обычное информационное сообщение', 123);
console.warn('Предупреждение (выделяется жёлтым)');
console.error('Сообщение об ошибке (выделяется красным)');
console.table([{ name: 'Анна', age: 20 }, { name: 'Иван', age: 22 }]); // Вывод данных в виде таблицы
```

### 5. Основы JavaScript: «Привет, мир!»
Чтобы добавить JavaScript-код на веб-страницу, используется HTML-тег `<script>`. Браузер автоматически выполняет всё, что написано внутри этого тега. Если скриптов много, их выносят в отдельные файлы с расширением `.js` и подключают через атрибут `src` (при этом код внутри самого тега `<script>` игнорируется).

Пример встроенного скрипта и подключения внешнего файла:

```html
<!DOCTYPE HTML>
<html>
<body>
  <!-- Встроенный скрипт -->
  <script>
    alert('Привет, мир!');
  </script>

  <!-- Подключение внешнего файла -->
  <script src="/js/script.js"></script>
</body>
</html>
```

### 6. Структура кода
Программа состоит из набора **инструкций** — отдельных команд, которые обычно разделяются точкой с запятой `;`. Перенос строки часто воспринимается как автоматическая точка с запятой, но в некоторых случаях это приводит к ошибкам, поэтому рекомендуется всегда ставить `;` в конце каждой команды.

Для пояснения кода используются **комментарии** — движок полностью игнорирует их при запуске. Однострочные комментарии начинаются с `//`, а многострочные заключаются между `/*` и `*/`:

```javascript
// Это однострочный комментарий, он действует до конца строки
alert('Привет');

/*
  Это многострочный комментарий.
  Он может занимать несколько строк.
*/
alert('Мир');
```

### 7. Строгий режим — `"use strict"`
Долгое время язык JavaScript развивался без нарушения обратной совместимости, поэтому в нём оставались старые, нелогичные особенности. Чтобы исправить это, в стандарте ES5 был введён **строгий режим**. Он активируется строкой `"use strict";` в самом начале файла или функции и запрещает потенциально опасные действия (например, использование переменной без её предварительного объявления).

Пример включения строгого режима:

```javascript
"use strict";

// В строгом режиме попытка записать значение в необъявленную переменную вызовет ошибку ReferenceError:
x = 5;
```

### 8. Переменные
**Переменная** — это именованное хранилище для данных. В современном JavaScript для создания переменных используются два ключевых слова: `let` (для значений, которые будут меняться в ходе программы) и `const` (для констант, которые нельзя перезаписать после создания). Устаревшее слово `var` сейчас почти не применяется, так как оно не учитывает блочную область видимости.

Пример объявления переменных и констант:

```javascript
let userName = 'Иван'; // Изменяемая переменная
userName = 'Алексей';  // Значение успешно изменено

const BIRTH_DATE = '01.01.2000'; // Константа, изменить её нельзя
```

### 9. Типы данных
JavaScript является динамически типизированным языком: переменная не привязана к конкретному типу и может хранить сначала число, а потом строку. Всего в языке **8 типов данных**:
1. **`number`** — целые и дробные числа, а также специальные значения `Infinity` (бесконечность) и `NaN` (ошибка вычислений).
2. **`bigint`** — целые числа произвольной длины (в конце добавляется буква `n`).
3. **`string`** — текстовые строки (в двойных `"..."`, одинарных `'...'` или обратных кавычках, которые позволяют встраивать переменные через `${...}`).
4. **`boolean`** — логический тип, принимающий только два значения: `true` (истина) или `false` (ложь).
5. **`null`** — специальное значение, означающее «ничего» или «значение неизвестно».
6. **`undefined`** — означает, что переменная была объявлена, но значение ей ещё не присвоено.
7. **`symbol`** — используется для создания уникальных идентификаторов.
8. **`object`** — сложные структуры данных (объекты, массивы, функции).

Чтобы узнать, какой тип данных находится в переменной, используется оператор `typeof`:

```javascript
let name = 'Илья';
alert(`Привет, ${name}!`); // Встраивание переменной в строку через обратные кавычки

typeof 0;         // "number"
typeof 10n;       // "bigint"
typeof true;      // "boolean"
typeof "foo";     // "string"
typeof undefined; // "undefined"
typeof null;      // "object" (официально признанная историческая ошибка языка)
```

### 10. Взаимодействие: `alert`, `prompt`, `confirm`
Для простого общения с пользователем в браузере есть три встроенные модальные функции. Они приостанавливают выполнение скрипта до тех пор, пока пользователь не закроет всплывающее окно.

Пример использования всех трёх окон взаимодействия:

```javascript
// 1. alert просто показывает сообщение и ждёт нажатия «ОК»
alert('Добро пожаловать на сайт!');

// 2. prompt выводит окно с полем ввода. Возвращает введённый текст или null при нажатии «Отмена»
let age = prompt('Сколько вам лет?', 18);

// 3. confirm задаёт вопрос с двумя кнопками: возвращает true («ОК») или false («Отмена»)
let isReady = confirm('Вы готовы продолжить?');
```

## Лекционное задание № 3. Основы JavaScript

### 1. Преобразование типов
Чаще всего операторы и функции автоматически приводят переданные им значения к нужному типу. Но при необходимости преобразование можно выполнить явно с помощью функций `String()`, `Number()` и `Boolean()`:
* **Строковое преобразование** превращает любое значение в текст (например, `false` становится строкой `"false"`).
* **Численное преобразование** происходит при математических операциях. Пустая строка и `null` превращаются в `0`, `true` — в `1`, `undefined` и строки с буквами — в `NaN`.
* **Логическое преобразование** превращает пустые значения (`0`, `""`, `null`, `undefined`, `NaN`) в `false`, а все остальные значения (даже строку `"0"`) — в `true`.

Примеры явного преобразования типов:

```javascript
String(123);       // "123"
String(null);      // "null"

Number("42");      // 42
Number("текст");   // NaN (ошибка преобразования)
Number(null);      // 0
Number(undefined); // NaN

Boolean(1);        // true
Boolean(0);        // false
Boolean("");       // false
Boolean("0");      // true (непустая строка всегда true)
```

### 2. Базовые операторы, математика
Помимо стандартных математических действий (`+`, `-`, `*`, `/`), в JavaScript есть оператор взятия остатка от деления `%` и возведения в степень `**`.

Важная особенность бинарного плюса `+`: если хотя бы один из его аргументов является строкой, он не складывает числа, а **склеивает строки** (конкатенация). А вот **унарный плюс** (поставленный перед одним значением) работает как `Number()` и превращает строку в число. Также для изменения переменной на 1 используются инкремент `++` и декремент `--`.

Примеры математических операций и работы со строками:

```javascript
5 % 2;       // 1 (остаток от деления 5 на 2)
2 ** 3;      // 8 (2 в степени 3)

'1' + 2;     // "12" (число 2 превратилось в строку и приклеилось к '1')
2 + 2 + '1'; // "41" (сначала сложились числа 2+2=4, потом приклеилась строка '1')

let apples = "2";
let oranges = "3";
alert(+apples + +oranges); // 5 (унарный плюс перевёл обе строки в числа)

let counter = 1;
let a = ++counter; // Префиксная форма: сначала увеличивает до 2, затем возвращает 2
let b = counter++; // Постфиксная форма: сначала возвращает текущее значение (2), затем увеличивает до 3
```

### 3. Операторы сравнения
Операторы сравнения (`>`, `<`, `>=`, `<=`, `==`, `!=`) всегда возвращают логическое значение `true` или `false`. Строки сравниваются посимвольно по алфавиту (точнее, по кодам символов Unicode).

Главное правило при проверке равенства: обычный оператор `==` (нестрогое равенство) перед сравнением приводит разные типы к числу, из-за чего `0 == false` даёт `true`. Оператор **строгого равенства `===`** сравнивает значения без приведения типов, поэтому он намного надёжнее.

Примеры строгого и нестрогого сравнения:

```javascript
'Кот' > 'Код';      // true (буква 'т' стоит в алфавите дальше буквы 'д')
'2' > 1;            // true (строка '2' приводится к числу 2)

0 == false;         // true (нестрогое равенство привело false к 0)
0 === false;        // false (строгое равенство: разные типы number и boolean)

null == undefined;  // true (специальное правило языка)
null === undefined; // false (разные типы)
```

### 4. Условное ветвление: `if`, `'?'`
Инструкция `if (...)` вычисляет условие в круглых скобках и, если результат истинный (`true`), выполняет блок кода. Для проверки дополнительных условий используется `else if`, а для выполнения кода в остальных случаях — `else`.

Когда нужно просто выбрать одно из двух значений в зависимости от условия, код можно сократить с помощью **тернарного оператора `?`**.

Пример использования `if...else` и тернарного оператора:

```javascript
let score = 85;

if (score >= 90) {
  console.log('Оценка: Отлично');
} else if (score >= 75) {
  console.log('Оценка: Хорошо');
} else {
  console.log('Оценка: Удовлетворительно');
}

// Короткая запись через тернарный оператор: условие ? если_да : если_нет
let age = 20;
let access = (age >= 18) ? 'Доступ разрешён' : 'Доступ запрещён';
```

### 5. Логические операторы
В JavaScript есть три основных логических оператора: `||` (ИЛИ), `&&` (И) и `!` (НЕ).
* **Оператор `||` (ИЛИ)** проверяет значения слева направо и возвращает **первое истинное значение** в его исходном виде (а если все ложны — возвращает последнее).
* **Оператор `&&` (И)** ищет и возвращает **первое ложное значение** (а если все истинны — последнее). Приоритет у `&&` выше, чем у `||`.
* **Оператор `!` (НЕ)** превращает значение в противоположное логическое (`true` в `false` и наоборот).

Примеры работы логических операторов:

```javascript
// || вернёт первое истинное значение:
let userName = null || '' || 'Гость'; // 'Гость'

// && вернёт первое ложное значение (или последнее, если все истинны):
alert(1 && 2 && null && 3); // null
alert(1 && 2 && 3);         // 3

// ! инвертирует значение, а двойное !! превращает любое значение в boolean:
!true;     // false
!!"текст"; // true
```

### 6. Операторы нулевого слияния и присваивания: `'??'`, `'??='`
Оператор нулевого слияния `??` возвращает первый аргумент, если он **определён** (то есть не равен `null` и не равен `undefined`), а иначе возвращает второй аргумент. Его главное отличие от `||` в том, что `||` считает число `0` и пустую строку `""` ложными и пропускает их, а `??` воспринимает `0` как нормальное, заданное значение.

Оператор нулевого присваивания `??=` записывает значение в переменную только тогда, когда она равна `null` или `undefined`.

Пример отличия `??` от `||` и работы `??=`:

```javascript
let height = 0;

alert(height || 100); // 100 (ошибка, так как 0 воспринимается как ложь)
alert(height ?? 100); // 0 (правильно, так как 0 не null и не undefined)

let userAge = null;
userAge ??= 18; // Присвоит 18, так как userAge был null
userAge ??= 25; // Оставит 18, так как значение уже задано
```

## Лекционное задание № 4. Основы JavaScript 2

### 1. Циклы `while` и `for`
Циклы позволяют многократно выполнять один и тот же участок кода:
* **`while`** проверяет условие перед каждым повторением и работает, пока оно истинно.
* **`do...while`** сначала выполняет тело цикла и только потом проверяет условие (гарантированно сработает минимум 1 раз).
* **`for`** используется, когда заранее известно количество повторений (содержит начало, условие и шаг).

Для управления ходом цикла используются директивы **`break`** (полностью останавливает цикл) и **`continue`** (пропускает оставшуюся часть текущей итерации и переходит к следующей). Чтобы выйти сразу из нескольких вложенных циклов, перед внешним циклом ставят **метку** (например, `outer:`).

Примеры всех видов циклов и директив управления:

```javascript
// 1. Цикл while
let i = 3;
while (i > 0) {
  console.log(i); // выведет 3, 2, 1
  i--;
}

// 2. Цикл do...while
let j = 0;
do {
  console.log(j); // выведет 0, 1, 2
  j++;
} while (j < 3);

// 3. Цикл for с использованием continue и break
for (let k = 0; k < 10; k++) {
  if (k % 2 === 0) continue; // пропускаем чётные числа
  if (k === 7) break;        // полностью выходим из цикла на числе 7
  console.log(k);            // выведет 1, 3, 5
}

// 4. Выход из вложенных циклов по метке
outer: for (let x = 0; x < 3; x++) {
  for (let y = 0; y < 3; y++) {
    if (x === 1 && y === 1) break outer; // прерывает оба цикла сразу
  }
}
```

### 2. Конструкция `"switch"`
Конструкция `switch` заменяет собой длинную цепочку условий `if...else if`. Она сравнивает переданное значение с каждым вариантом `case` на **строгое равенство (`===`)**. В конце каждого блока `case` обязательно ставится `break`, иначе код продолжит выполняться в следующих блоках без проверки условий. Блок `default` срабатывает, если ни один из вариантов не подошёл.

Пример использования `switch` с группировкой вариантов:

```javascript
let browser = 'Chrome';

switch (browser) {
  case 'Edge':
    alert('У вас браузер Edge!');
    break;

  // Несколько вариантов case можно объединить для одного действия:
  case 'Chrome':
  case 'Firefox':
  case 'Safari':
    alert('Этот браузер полностью поддерживается');
    break;

  default:
    alert('Неизвестный браузер');
}
```

### 3. Функции (Function Declaration)
**Функция** — это основной строительный блок программы, позволяющий не дублировать один и тот же код. Переменные, объявленные внутри функции, являются **локальными** и не видны снаружи. Для возврата результата работы используется директива `return` (если её нет, функция возвращает `undefined`). В параметрах можно указать значения по умолчанию на случай, если аргумент не был передан при вызове.

Важная особенность объявления через `function имя()` (**Function Declaration**): движок создаёт такие функции до запуска скрипта, поэтому их можно вызывать в коде даже **раньше** строки, где они объявлены.

Пример объявления функции с параметром по умолчанию и `return`:

```javascript
// Вызов работает даже до объявления функции:
alert(showMessage('Анна')); // "*Анна*: текст не добавлен"

function showMessage(from, text = 'текст не добавлен') {
  from = '*' + from + '*'; // изменяем локальную копию параметра
  return `${from}: ${text}`; // возвращаем итоговую строку
}
```

### 4. Function Expression
Помимо классического объявления, функцию можно создать внутри выражения и записать в обычную переменную — это называется **Function Expression** (функциональное выражение). В отличие от Function Declaration, такая функция создаётся только в тот момент, когда выполнение кода доходит до этой строки, поэтому вызвать её заранее нельзя.

Поскольку в JavaScript функция является обычным значением, её можно передавать как аргумент в другую функцию — такие функции называют **колбэками (callback)**.

Пример Function Expression и передачи функции-колбэка:

```javascript
// Создание функции через присваивание в переменную:
let sayHi = function() {
  alert('Привет!');
};

// Передача функций-колбэков (yes и no) в качестве аргументов:
function ask(question, yes, no) {
  if (confirm(question)) yes();
  else no();
}

ask(
  'Вы согласны с правилами?',
  function() { alert('Вы согласились.'); },
  function() { alert('Вы отменили выполнение.'); }
);
```

### 5. Стрелочные функции, основы
**Стрелочные функции (`=>`)** — это более короткий и удобный способ записи Function Expression. Если тело функции состоит из одного выражения, фигурные скобки `{ ... }` и слово `return` можно не писать — результат вернётся автоматически. Если же функция занимает несколько строк в фигурных скобках, `return` нужно указать явно.

Примеры разных форм записи стрелочных функций:

```javascript
// 1. С несколькими аргументами (неявный возврат результата):
let sum = (a, b) => a + b;

// 2. С одним аргументом (круглые скобки можно опустить):
let double = n => n * 2;

// 3. Без аргументов (пустые скобки обязательны):
let sayHello = () => alert('Привет!');

// 4. Многострочная стрелочная функция (требует фигурных скобок и явного return):
let calculate = (a, b) => {
  let result = a * b;
  return result + 10;
};
```

### 6. Особенности JavaScript (итоговая сводка)
Подводя итог изученным основам языка, можно выделить ключевые правила и особенности JavaScript:
1. **Разделение команд:** инструкции разделяются точкой с запятой `;`. Нельзя делать перенос строки сразу после `return`, иначе движок автоматически поставит `;` и вернёт `undefined`.
2. **Строгий режим:** директива `"use strict"` в начале файла включает современный стандарт выполнения и защищает от случайных глобальных переменных.
3. **Область видимости:** переменные `let` и `const` видны только внутри своего блока `{ ... }`.
4. **Динамическая типизация:** в языке 8 типов данных (`number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `symbol`, `object`), и переменная может менять свой тип.
5. **Сравнение и логика:** оператор `===` проверяет строгое равенство без приведения типов, `??` реагирует только на `null` и `undefined`, а `||` и `&&` возвращают исходные операнды.
6. **Гибкость функций:** функции являются объектами-значениями, их можно копировать в переменные, передавать как колбэки и записывать в трёх формах (*Function Declaration*, *Function Expression* и *стрелочные функции*).

Пример, объединяющий ключевые особенности (строгий режим, `const`/`let`, `??` и стрелочную функцию):

```javascript
"use strict";

const DEFAULT_DISCOUNT = 10;

// Стрелочная функция использует оператор нулевого слияния ?? для подстановки скидки по умолчанию:
const getFinalPrice = (price, discount) => {
  let appliedDiscount = discount ?? DEFAULT_DISCOUNT;
  return price - (price * appliedDiscount / 100);
};

console.log(getFinalPrice(1000, 0));    // 1000 (скидка 0% учтена корректно благодаря ??)
console.log(getFinalPrice(1000, null)); // 900 (применена скидка по умолчанию 10%)
```
